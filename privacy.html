Privacy policy

Last updated: 2026-10-27

What the app accesses

With the channel owner's permission, gongjang analytics reads YouTube Analytics and YouTube Data for the owner's own channels: video titles, publish dates, durations, views, watch time, subscribers gained, impressions, impressions click-through rate, average view duration, average percentage viewed and audience retention. Access is read-only.

How the data is used

The data is saved as files on the owner's own computer and used only to compare the owner's videos and improve future videos.

Sharing

The data is not sold, not shared with anyone, not used for advertising and not sent to any other server.

Keeping and deleting

The owner can delete the saved files at any time and can remove the app's access at any time at myaccount.google.com/permissions.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions: open an issue in this site's repository on GitHub.
