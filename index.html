gongjang analytics

A private tool that reads YouTube Analytics reports (views, impressions, click-through rate, average view duration, audience retention) for the owner's own YouTube channels, so the owner can see why each video worked or not.

It only requests read-only access (yt-analytics.readonly, youtube.readonly). It never uploads, edits or deletes anything on YouTube.

It is used only by the owner of this project for the owner's own channels. It is not offered to the public.
